研究输入：用户提供的 `web-ai-frontier-round2-20261024.md` 及引用会话「调研改造前端」。日期为 2026-10-24，Asia/Shanghai。实施基线 `2da13553338fd8862b4b197ea16ff8192e882f27`，初始工作区干净；分支 `codex/ai-workspace-round2`。本轮本地实施、检查与分项提交，不推送、不部署。

## 范围与依赖

保留首轮主题、locale 事务、动态资源与共享 SSE。优先完成 Home 选择范围并提问 → Explore/Search 真实终态 → 并排核验证据 → 预览/下载已有成果的完整切片。候选框架只在同题隔离比较后决定是否采用；没有收益或真实 action 合同的实验可以退出，不能宣称生产能力已完成。

| 波次  | owner               | 独占写入范围                                                  | 完成条件                                                           |
| ----- | ------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------ |
| W0    | request_identity    | APIClient、请求身份回归、MCP ownership 测试                   | 迟到旧身份无会话副作用；按可观察状态等待且保留污染断言             |
| W0    | explore_lifecycle   | Explore、AppChatAnswer 的运行展示边界                         | 每消息真实终态、EOF/本地停止/失败保留正文、历史未知不推断成功      |

## 显示合同

`src/lib/ai-workspace/contracts.ts` 只定义显示合同与纯快照，不持有请求、不读写 API、不持久化内容。运行继续用已有 RunPhase，未知历史允许未标注；本地订阅与服务端结局分开。ContextManifest 只表达 selected/submitted，资源来自真实请求字段；没有回执就不显示已使用。引用与成果共享容器，身份和数据分别处理。

| 能力     | 本轮边界                                                                            |
| -------- | ----------------------------------------------------------------------------------- |
| 上下文   | 选择/提交快照；ready 等可用性只按已有数据声明                                       |
| 引用     | 现有片段、受保护原文入口；无定位/原文明确提示                                       |
| 成果     | 已有 artifact endpoint 的鉴权读取、只读预览、下载；无保存/版本 API 时不提供这些动作 |
| 运行控制 | 本地停止；不新增持久运行、取消确认、queue/steer 或审批 API                          |
| surface  | 注册组件/动作白名单及 scope；没有真实 action 接收路径时保持实验关闭                 |

## 验收

各 owner 跑对应专项并读回结果。源码稳定后统一运行正式测试 inventory/CI、Web 类型与构建、lint、file-size、i18n/type contract、主题生成一致性、bundle budget；平台接线变更覆盖 client-platform。UI 实际检查宽屏正文与证据同时可交互、窄屏焦点归还、主题/locale/草稿不重挂、终态与迟到响应、成果失败与资源释放。性能分别记录 manifest 静态闭包、冷启动网络与首次打开增量，不把总 raw 当首页下载。最终结果另写验收文档；本文件仅记录计划。
