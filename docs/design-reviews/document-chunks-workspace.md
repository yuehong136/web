# 文档切片审阅工作区

2026-10-04。目标是让知识库维护者检查实际用于检索的内容、对照原文并修订切片。

## 判断与参考

旧页面默认同时打开 560px 原文、切片列表和 320px 信息面板。原文读取失败时仍占据主要空间，列表操作隐藏在 hover 中，分页与标识在剩余宽度内换行。信息区重复解释元数据并套用大卡片，文件名在导航中退化为文档 ID。

参考 [Dify 文档与切片维护](https://docs.dify.ai/en/cloud/use-dify/knowledge/manage-knowledge/maintain-knowledge-documents) 的内容审阅、启禁用、关键词与图片维护，以及 [RAGFlow 切片管理](https://ragflow.io/docs/v1.0.0-rc1/chunk_parsing_results_and_knowledge_fragment_management) 的原文定位、搜索筛选和全文切换。这些资料用于确认主要工作任务；布局按本产品现有能力重新设计。

采用连续阅读区，不把每个切片再包装成浮动卡片。序号代表真实切片顺序，页码表示原文位置；状态、字符数和操作退到正文上方。颜色与字体沿用产品令牌和现有中英文字体栈，避免引入第二套视觉系统。浅色基础为 surface/default 与 primary/secondary 文字，深色自动使用同名令牌；仅焦点、选中、检索状态使用强调色。

## 布局与交互

```text
知识库 / 库名 / 切片
文件名与用途说明             原文对照  文档信息  添加切片
搜索内容                    状态筛选  摘要/全文
选择本页、结果数量           有选择时显示批量操作
切片顺序与来源页 / 状态 / 操作
切片正文（点击或 Enter/Space 展开）
……
当前范围                    每页数量 / 前后翻页
```

- 初始页面集中阅读切片；原文与信息默认关闭。
- 原文开启后，工作区宽度至少 960px 时使用 `react-resizable-panels`。分隔条支持鼠标及键盘，原文范围限制为 30%–55%，正文至少占 45%。宽度按实际工作区测量，二级导航展开也能正确降级。
- 窄工作区使用原文抽屉；文档信息与编辑各使用独立 Radix Sheet，关闭后恢复触发按钮焦点。
- 摘要保持三行，当前选中切片单独展开全文；批量选择与正文展开相互独立。编辑按钮始终可见，并保留双击编辑。
- 搜索常显，400ms 防抖；Escape 清空搜索。状态筛选保持服务端分页与总数合同。换搜索、筛选、页码或每页数量后清除批选。
- 紧凑分页保留 10/20/30/50 个切片选项，页底菜单向上展开；导航改变时回到阅读区顶部，普通内容修改不重置阅读位置。
- 原文失败显示安全的本地化说明、重试和关闭入口。文档信息使用分节属性行，元数据编辑与图片预览使用 Radix Modal，支持嵌套焦点与单层 Escape。

## 实现边界

页面编排、阅读组件、表单、请求与面板状态分别维护。移除旧的手算像素拖拽 hook、闲置列表状态组件与搜索显隐状态。复用 Console/Workspace 模板、PageHeader、PageToolbar、PageStates 和现有设计令牌。

继续使用领域 API、Query key 工厂、SafeHtml 白名单、dataset 图片资源租约与原文 positions 高亮。协议字段、模型/用户内容保持原文，中英 UI 文案同步。

同时修复跨文档状态残留：请求显式绑定知识库/文档，图片转码和网络请求覆盖同步操作锁，过期表单完成不能关闭新草稿。切换路由清空页面状态，切换切片清空替换图片；失败保留草稿。未读取文档、失败或占位列表期间不允许写入；保存期间锁定编辑区。
